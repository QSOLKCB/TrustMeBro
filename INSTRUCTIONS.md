# Field instructions

Reduce all six defendants’ confidence to zero while keeping your patience above zero. Each case has three rotating claims. Attacking advances the current claim; inspecting does not.

| Command | Cost / effect |
| --- | --- |
| `start` | Clock in and open the first case. |
| `inspect` | Spend 3 patience, collect one receipt, and reveal the current claim’s best instrument. Once per claim. |
| `audit` | Spend 7 patience; 16 base confidence damage. Best for financial claims. |
| `factcheck` | Spend 6 patience; 14 base damage. Best for technical promises and inconsistent standards. |
| `subpoena` | Spend 10 patience and one receipt; 20 base damage. Best for concealed records. |
| `coffee` | Restore up to 18 patience, once per case. Full patience preserves the allocation. |
| `roast` | Spend 4 patience; deal 8 confidence damage and earn a contempt citation. Once per case. |
| `next` | Advance after a sanction. You cannot skip an open case. |
| `status` | Show resources and any inspected weakness. |
| `help` | Open the field manual. Escape closes it. |
| `manifesto` | Show a link to the scorched declaration in a separate tab. |
| `clear` | Clear the visible terminal; preserve the export archive. |
| `restart` | Reset the campaign and its transcript archive. |

A matched instrument deals **24 extra damage**. An inspected claim adds **8 extra damage**. Inspecting the same claim again never creates another receipt. Receipts carry across cases; coffee and roast allowances reset.

Closing a case restores up to **16 patience**. An attack that reduces patience to zero loses the shift, even if it also reduces confidence to zero. Request coffee before this happens.

Use the action buttons or type commands. Press Enter to execute, Up/Down for command history, and Tab to complete a command. The terminal is a game, not a shell.

The **Export receipts** button downloads the full current shift as a text file, including output you cleared from the visible terminal. Refreshing the page starts over.

Try `sudo`, `trust`, `funding`, `synergy`, `blockchain`, `agi`, `truth`, `determinism`, or `provenance` if your contempt requires supplementary documentation.
