# TrustMeBro

**Big claims. Little receipts.** A virtual terminal game of bureaucratic warfare against six fictional Silicon Valley archetypes. A QSOL-IMC public disservice.

[Play on GitHub Pages](https://qsolkcb.github.io/TrustMeBro/) · [Read the scorched manifesto](https://qsolkcb.github.io/TrustMeBro/manifesto.html) · [Field instructions](INSTRUCTIONS.md)

You work at the **Department of Unsubstantiated Confidence**. Inspect claims, collect receipts, choose an audit, fact-check, or subpoena, and sanction every bro before your patience runs out. Coffee is requisitioned in triplicate. Contempt is proudly retained. The final verdict is suitably Australian.

- Six defendants, eighteen claims, matched attacks, resource management, and win/loss endings.
- A working command terminal with history, completion, field manual, and downloadable receipts.
- **The Manifesto of the Unimpressed**: eight scorched articles on determinism, truth, provenance, falsifiability, and institutional bullshit.
- Responsive, keyboard accessible, and dependency-free. No accounts, analytics, external assets, or game network requests.

Static HTML/CSS/JavaScript; no build step. GitHub Pages can serve `main` → `/ (root)` after this change is merged. `.nojekyll` keeps it a plain static site. For local use, see [GETTING_STARTED.md](GETTING_STARTED.md).

All defendants and proceedings are fictional satire. Nothing is sent to anyone. The existing [Apache-2.0 licence](LICENSE) applies.
